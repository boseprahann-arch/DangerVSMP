STEP-BY-STEP GUIDE

How to Set Up & Join DangerVSMP

Follow these steps in order on Minecraft: Java Edition to get Fabric, Voice Chat, and join the server.

!
Why Fabric 26.2 (0.20.1) instead of Vanilla?

Even though DangerVSMP is pure survival, you need to launch Minecraft with Fabric 26.2 (Loader 0.20.1) instead of the default Vanilla profile. We only put Simple Voice Chat and no other mods — just pure survival. Fabric does not change Vanilla gameplay; it just allows Voice Chat to work.

01

Set Up Fabric 26.2 (Loader 0.20.1)

For the Normal / Official Minecraft Launcher: download and run the official Fabric Installer for Minecraft: Java Edition. Select Minecraft Version: 26.2 and Loader Version: 0.20.1, then click Install to create your Fabric launch profile.

Download Fabric Installer ↗

For Cracked Launchers: in whatever launcher you are playing, change whatever version you are currently playing (Vanilla or anything else) to Fabric 26.2 (0.20.1) directly in your launcher's version selector. Then continue to Step 2 below.

02

Download Fabric API & Simple Voice Chat from Modrinth

Go to Modrinth and download both .jar files below for Minecraft 26.2 (Fabric) — these are the only mods used:

1. Fabric API Required

On Modrinth, choose version 0.161.0+26.2 (for Fabric 26.2). Needed so Simple Voice Chat can work properly.

Modrinth: Fabric API ↗
2. Simple Voice Chat Voice Chat

On Modrinth, you will see two options — choose 2.6.22+26.2 (Fabric). Lets you talk to and hear other players in-game; without it, you will only have normal text chat.

Modrinth: Simple Voice Chat ↗
03

Put Both Mods in Your AppData mods Folder

Move both downloaded .jar files (Fabric API and Simple Voice Chat) into your Minecraft mods folder inside AppData:

%appdata%\.minecraft\mods
  1. Press Win + R on your keyboard to open the Run dialog.
  2. Paste %appdata%\.minecraft\mods and press Enter (if the mods folder doesn't exist yet, create it inside .minecraft).
  3. Drop both the Fabric API and Simple Voice Chat .jar files into that folder.
04

Add the Server & Join DangerVSMP

Open the Minecraft Launcher, select your Fabric profile, click Play, and then follow these steps:

  1. Click Multiplayer → Add Server.
  2. In Server Name, type whatever you want (for example: DangerVSMP).
  3. In Server Address / IP, paste the full IP (the port 30776 is already included):
    DangerVSMP.aternos.me:30776
  4. Click Done / Save / OK.
  5. Select DangerVSMP from your server list, click Join Server, register in-game when prompted, and start playing!
